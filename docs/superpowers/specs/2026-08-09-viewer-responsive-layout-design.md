# Viewer 响应式布局设计

## 背景

Web 版 viewer 当前以固定的 `1920 x 1080` 初始化窗口。浏览器窗口尺寸变化后，canvas 的 CSS 尺寸虽然会变化，但 raylib 的绘制尺寸和 viewer 内部布局仍按初始窗口工作。详情面板中的矿物行也会持续向下绘制，矿物种类较多时会越过窗口底部。

## 目标

- Web 版 viewer 使用浏览器当前可用尺寸，并在窗口变化后同步更新 raylib 窗口尺寸。
- 右侧详情面板保持固定的可读宽度，主场景占据剩余区域。
- 矿物列表超出面板可用高度时，仅列表区域滚动，不遮挡面板底部操作提示。
- 桌面版保持当前固定面板和可调整窗口行为，不引入与本次需求无关的渲染或数据变化。

## 设计

### Web 窗口尺寸

raylib 的 Web 后端已经注册浏览器窗口 resize 回调，并在回调中同步 canvas 和内部绘制尺寸。viewer 只在 `InitWindow` 前读取 `document.documentElement.clientWidth/clientHeight`，让首次绘制使用浏览器当前 viewport，而不是桌面端的固定 `1920 x 1080`。尺寸下限使用一个小的正数，避免浏览器过渡状态产生零尺寸绘制目标。

shell 页面继续让 canvas 铺满 viewport，并禁止页面滚动；实际绘制区域由 raylib 的窗口尺寸决定。

### 详情面板

将面板绘制拆成三个区域：

1. 顶部标题和参数区；
2. 矿物列表滚动区；
3. 面板底部的操作提示区。

矿物列表使用 viewer 自己维护的滚动偏移，不依赖桌面窗口或浏览器 DOM。列表区域绘制前设置 scissor，绘制后恢复 scissor。鼠标滚轮位于右侧面板且列表内容超过可视高度时，更新滚动偏移；场景相机只在鼠标不位于面板时处理滚轮缩放。

面板绘制函数接收列表区域的垂直边界和滚动偏移，普通参数行仍从顶部开始绘制。矿物列表的实际高度用于计算最大滚动距离，滚动偏移在面板切换、窗口尺寸变化和内容变化后限制在有效范围内。

### 小窗口处理

面板宽度继续使用现有的 `326` 像素。窗口高度不足时，顶部信息区和底部提示区保持在窗口内；矿物列表区至少保留一个很小的可视高度。窗口宽度小于面板宽度时，面板仍停靠在右侧，主场景区域收缩为零或很小区域，但不改变数据和交互状态。

## 数据流与兼容性

- 不修改星体、行星、矿物数据生成及排序。
- 不新增或删除随机调用。
- Web resize 只影响窗口和 UI 几何，不影响生成结果。
- 桌面端继续使用 raylib 的可调整窗口；滚动列表行为统一适用于桌面和 Web。

## 验证

- 构建 Debug viewer，关闭 viewer 以外的无关目标。
- 构建 Release viewer。
- 在固定尺寸桌面窗口运行，确认星系视图、系统视图、选择和返回操作仍可用。
- 在 Web 构建中检查初始窗口尺寸和 resize 后的 `GetScreenWidth()` / `GetScreenHeight()` 布局。
- 使用长矿物列表确认列表边界内滚动，底部提示不被矿物行覆盖。
- 检查 Web 页面无空白页、无运行时错误，并分别观察桌面尺寸和移动尺寸截图。
